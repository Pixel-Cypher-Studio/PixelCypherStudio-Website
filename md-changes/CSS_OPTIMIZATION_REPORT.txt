IMPORTANT TECHNICAL NOTE — TURBOPACK KEYFRAME SCOPING
------------------------------------------------------
CSS Modules with Turbopack (Next.js default bundler) scopes @keyframes
animation-name references to the local module file. A @keyframes defined in
globals.scss is INVISIBLE from inside a .module.scss file — the animation will
silently do nothing.

Rule: Any .module.scss file that uses an animation: property MUST define the
corresponding @keyframes locally in that same file.

Files that currently have local keyframe definitions (correct):
  - Hero.module.scss         → pulse-glow, fadeUp
  - Navbar.module.scss       → pulse-glow (dot indicator version), overlayItemIn
  - Footer.module.scss       → pulse-glow (dot indicator version)
  - Marquee.module.scss      → marquee

Note: The Navbar/Footer pulse-glow is intentionally different from the global
one (opacity 1→0.4 for dots, vs var(--orb-opacity) for background blobs).
CSS Modules scoping ensures they don't conflict despite sharing a name.
